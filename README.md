# 🐱 Random Cat Image Viewer

A simple and visually appealing web project that fetches and displays a random cat image using an external API. Designed with clean animations, soft shadows, and a modern glassmorphism-inspired layout.

## 💡 Features

- Fetches random cat images from the [Cat API](https://cataas.com).
- Smooth fade-in animation on image load.
- Stylish responsive layout with soft gradients and shadows.
- One-click experience — press the button to get a new cat!

## 📦 Technologies Used

- HTML5
- CSS3 
- JavaScript (Fetch API)
